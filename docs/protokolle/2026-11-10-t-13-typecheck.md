# Protokoll T-13: Typecheck als Pflicht-Check

> Datum: 2026-11-10 · Task: T-13 · AK: AK-1 · PR: codeslage/werkstatt#8

## Ablauf

1. Neuer CI-Job „Typecheck“ (`pnpm typecheck` über alle Workspace-Pakete).
2. Negativprobe lokal: Eine Datei mit absichtlichem Typfehler (`TS2322`) lässt `pnpm typecheck` mit Exit 1 abbrechen. Danach wurde sie entfernt, und der Lauf endet wieder mit Exit 0. Der Review-Agent hat außerdem gezeigt, dass `noUncheckedIndexedAccess` und implizites `any` tatsächlich abgelehnt werden.
3. Beide Jobs liefen im PR grün.
4. Ruleset `main-schutz` per API ergänzt: Pflicht-Checks sind jetzt **„Secret- und Öffentlich-Scan“ und „Typecheck“**. Gegenprobe ohne Login über `GET /repos/codeslage/werkstatt/rules/branches/main` zeigt beide.

## Regel für künftige Tasks

Jeder neue CI-Job, der einen Merge blockieren soll, wird **im selben PR** als Pflicht-Check ins Ruleset eingetragen, sobald er einmal grün gelaufen ist, und im Protokoll der Task vermerkt. Sonst lässt sich ein PR trotz rotem Job mergen.
