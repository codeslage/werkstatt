3. **Umsetzung:**
   - Header: Zeichen `logo-zeichen.svg` (Relief, aus `gestaltung/`) als Bild mit leerem `alt`, also nur Schmuck. Daneben die Wortmarke als echter Text in Mono: „code“ mit Gewicht 300 in Nebentextfarbe, „slage_“ mit Gewicht 800 in Textfarbe.
   - `apple-touch-icon.png` (180 × 180, ohne Transparenz) aus dem flachen Zeichen `logo-zeichen-flach.svg`, gerendert mit dem Chromium von Playwright. Damit kommt keine neue Abhängigkeit dazu.

     Nachbauen (im Ordner `apps/web`, das Skript liegt nur als Datei `.icon.tmp.mjs` und wird danach gelöscht):

     ```js
     import { readFileSync } from 'node:fs';
     import { chromium } from '@playwright/test';
     const [svgPath, outPath] = process.argv.slice(2);
     const svg = readFileSync(svgPath, 'utf8');
     const browser = await chromium.launch();
     const page = await browser.newPage({ viewport: { width: 180, height: 180 } });
     await page.setContent(
       `<html><body style="margin:0;background:#1E2228">${svg.replace('<svg ', '<svg width="180" height="180" ')}</body></html>`,
     );
     await page.screenshot({ path: outPath });
     await browser.close();
     ```

     Aufruf: `node .icon.tmp.mjs ../../specs/06-webseite/gestaltung/logo-zeichen-flach.svg public/apple-touch-icon.png`
