### Zusammenfassung für den Inhaber
Die Änderung fügt eine automatische Prüfung hinzu, die Code ohne Nutzen findet: verwaiste Dateien, Funktionen, die niemand aufruft, und Pakete, die zwar installiert, aber nicht verwendet werden. Die Prüfung ist jetzt Pflicht, bevor etwas nach `main` darf. Beim ersten Lauf hat sie schon eine echte Kleinigkeit im Repo gefunden, die behoben wurde. Ein Risiko besteht nicht. Es gibt eine Schwäche: Die Tests beweisen, dass das Werkzeug grundsätzlich funktioniert, aber nicht, dass unsere eigene Einstellung es nicht später unbemerkt abschwächt. Das sollte noch nachgezogen werden. Zum Ausprobieren eignet sich ein Test-PR, der eine neue, nirgends genutzte Funktion exportiert. Die Prüfung „Knip“ muss dann rot werden und den Merge blockieren.
