### Zusammenfassung für den Inhaber

Die Änderung macht das Register der Zugangsdaten vollständig. Es fehlten der automatische GitHub-Token der CI, Ihr lokaler GitHub-CLI-Login und die Claude-App. Ein neuer Abschnitt hält fest, dass das Register am 18.11. mit den tatsächlich vorhandenen Tokens bei GitHub und Cloudflare abgeglichen wurde. Vertrauliche Angaben wie Werte, IDs, Mail-Adressen oder der Registrar stehen nicht darin. Das Risiko ist gering, aber die drei neuen Einträge werden auf GitHub nicht als Tabellenzeilen angezeigt, sondern als unleserlicher Textblock. Das sollte noch korrigiert werden. Öffnen Sie danach `docs/secrets.md` auf GitHub und prüfen Sie, ob alle zehn Einträge in einer Tabelle stehen.
