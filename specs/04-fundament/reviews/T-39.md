### Zusammenfassung für den Inhaber

Ab jetzt vergleicht GitHub jeden Montag und bei jeder Infrastruktur-Änderung den Code mit dem, was bei Cloudflare tatsächlich eingestellt ist. Weicht etwas ab, wird der Lauf rot und GitHub schickt eine Mail. Dafür nutzt die CI nur Schlüssel, die lesen, aber nichts ändern können. Dem lokalen Schreibschlüssel ist das breite Speicherrecht entzogen. Das Risiko ist gering. Ich habe ausdrücklich geprüft, dass weder im Repo noch im öffentlichen Log des ersten Laufs Registrar, Konto- oder Zonen-IDs auftauchen. Vor dem Merge sollte noch der Task-Status von T-39 samt Ist-Zeit nachgetragen werden. Zum Ausprobieren: unter Actions → „Drift-Check“ → „Run workflow“ einen Lauf starten. Er sollte grün sein, und im Log sollten statt IDs nur `<id>` bzw. `***` stehen.
